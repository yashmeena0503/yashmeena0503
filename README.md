Go economy API that’s easy to extend for new platforms,

packed with powerful features and built for speed.

## Self-hosting

I've run my own Proxmox setup with Debian VMs and Docker, hosting webapps, databases, moderation bots, micro-services, and a bunch of game servers (Minecraft, ARK, and more).

- **Networking:** Nginx / Nginx Proxy Manager for reverse proxying and domain routing, WireGuard/OpenVPN for direct access to internal services
- **Monitoring:** Prometheus, Grafana, and Zabbix
- **Game servers:** mostly on [Pterodactyl](https://pterodactyl.io/), with custom shell install scripts for games that had no up-to-date eggs, and some on plain systemd services for better performance and easier access
